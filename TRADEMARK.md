# TLL OS Trademark Policy

> **Important**: Open source code does not mean open trademark.

## Summary

TLL OS source code is licensed under Apache License 2.0. You are free to use, modify, and distribute the code.

However, the **TLL OS name, logo, and trademarks are NOT covered by the Apache License**. They are protected independently.

## What You CAN Do

- Use TLL OS code in your own projects (commercial or non-commercial)
- Modify and redistribute TLL OS source code
- Build applications, modules, plugins, and adapters for TLL OS
- Say "built with TLL OS" or "compatible with TLL OS Protocol"
- Use the TLL OS name in documentation, tutorials, and references that accurately describe the project
- Fork the code and create your own runtime implementation (but NOT call it "TLL OS")

## What You CANNOT Do

- Use the TLL OS name, logo, or trademarks for your own product or service without permission
- Call your fork or modified version "TLL OS"
- Use the TLL OS trademark in a way that implies official endorsement or affiliation
- Register domain names containing "tll-os" or "tllos" that could cause confusion
- Use the TLL OS logo on merchandise, packaging, or marketing materials without permission
- Create a "TLL OS Certified" or similar certification program without authorization

## Naming Your Fork or Derivative Work

If you fork TLL OS or create a derivative runtime, you MUST use a different name. Examples:

- ✅ "MyRuntime — a TLL OS Protocol compatible runtime"
- ✅ "AcmeOS — built on TLL OS Protocol 2.0"
- ❌ "TLL OS Fork"
- ❌ "TLL OS Enterprise" (without authorization)
- ❌ "New TLL OS"

You may reference TLL OS Protocol in your product name as a descriptor (e.g., "compatible with TLL OS Protocol 2.0"), but TLL OS must not be the primary name of your product.

## Official Use

The following are authorized to use the TLL OS trademark:

- The official TLL OS project and its maintainers
- TLL Cloud (official commercial services)
- TLL Enterprise (official enterprise offerings)
- Entities with explicit written permission from the trademark holder

## Contact

For trademark questions, permissions, or reporting misuse, contact the TLL OS project maintainers through the official GitHub repository.
