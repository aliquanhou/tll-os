# TLL OS Proposals (TEP)

This directory contains TLL Evolution Proposals (TEPs).

## What is a TEP?

A TEP is a structured proposal for changing the TLL OS Protocol or Runtime. Both humans and AI Agents can submit TEPs.

## How to Submit

1. Read [`docs/evolution/TEP.md`](../docs/evolution/TEP.md) for the full process
2. Create a file `TEP-XXXX-your-title.md` in this directory
3. Follow the TEP structure (see TEP.md for template)
4. Implement your ChangeSet
5. Run `npm test` — all 15 tests must pass
6. Submit a Pull Request

## TEP Types

- `feature` — New feature or capability
- `bugfix` — Bug fix
- `breaking` — Breaking change (requires RFC + migration guide)
- `deprecation` — Deprecate a contract or feature
- `refactor` — Refactor without behavior change
